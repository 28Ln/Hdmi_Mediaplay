# I2C 调试页 — 真机实测（RK3568，2026-10-20）

Debug 包启动即进入本页。

## 页面结论（实测）

| 区块 | 实测结果 |
|---|---|
| ① 总线状态 | **不通 · 从机无应答 (ENODEV)**；探测方式 `sysfs: version（存在但读失败）` |
| ② 驱动节点 | **存在 14 / 14**（含 `version`、`status`、`result`、`cmd_count`、`rx_state`） |
| ② 节点读数 | 全部返回 `ENODEV 从机不应答` |
| ③ 持续写 | 自动启动，1 秒一次；计数持续增长，最近错误 `read failed: ENODEV (No such device)` |

## 这组数据说明了什么

节点齐全 + 权限 0666 + 读取全部 `ENODEV`
= **驱动已绑定，但 I2C 从机没有 ACK**。

`i2cdetect -y 4` 曾显示 `30: UU` —— 注意 `UU` 表示该地址**被驱动占用**，
**不代表总线上有应答**。这是本次排查中最容易误判的一点。

需要硬件侧确认：从机供电、SDA/SCL 上拉、地址跳线、pinmux 是否切到 i2c4。
