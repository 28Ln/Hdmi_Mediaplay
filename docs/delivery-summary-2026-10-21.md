## 三、SAME 四格同步（唯一完成的验收项）

### 方法

用 ffmpeg 生成 **60 秒 25fps、画面内嵌时间码与帧号** 的测试片，
四格同播，从截图直接读出每格的真实帧。

（此前用 4 秒片子测不出——几乎全程落在循环边界保护窗口）

### 结果

| 采样 | P1 | P2 | P3 | P4 | 最大偏差 |
|---|---|---|---|---|---|
| 1 | 33.200 / 830 | 33.160 / 829 | 33.240 / 831 | 33.160 / 829 | **40ms** |
| 2 | 41.360 / 1034 | 41.440 / 1036 | 41.440 / 1036 | 41.320 / 1033 | **120ms** |
| 3 | 34.040 / 851 | 34.120 / 853 | 34.160 / 854 | 34.000 / 850 | **160ms** |
| 4（Release 包） | 29.320 / 733 | 29.360 / 734 | 29.360 / 734 | 29.240 / 731 | **120ms** |
| 5（Release 包） | 03.720 / 93 | 03.760 / 94 | 03.760 / 94 | 03.640 / 91 | **120ms** |
| 6（Release 包） | 39.960 / 999 | 40.040 / 1001 | 40.000 / 1000 | 39.880 / 997 | **160ms** |

**最大 4 帧（160ms），在滞回带内。36 秒观察：0 次 seek、0 次解码错误。**

> Debug 与 Release 两个包都验证过，结果一致。
> Release 包的客户 UI（大字图标底栏）不影响同步行为。

### 关键修复

1. **自适应检查间隔**：按视频时长调整（duration/2，500ms~3s）
2. **滞回**：`TRIM_ENTER_MS=120` 进入纠偏、`TRIM_RELEASE_MS=40` 才恢复常速
   —— 无滞回时实测在 −263ms ↔ +137ms 之间每 8 秒振荡，永不收敛

## 四、I2C 阻塞项（需硬件方）

### 结论

**i2c-4 整条总线无信号，不是 0x30 单点故障。**

### 决定性证据

| 实验 | 结果 |
|---|---|
| **全地址扫描**（0x08/0x2f/0x30/0x31/0x50/0x68/0x76/0x77） | **全部超时 12~40 秒** |
| 对照 i2c-1 探测不存在的地址 | **265ms 返回 `No such device`** |
| 解绑驱动后 `i2cget` 直连 0x30 | 仍 `Connection timed out` |
| `force-stop` App 后 30 秒 | 仍有 20 次超时（来自驱动自身） |
| 同一毫秒对照 i2c-1 | `LT86204: 38 b0 ff 00` 正常 |

正常总线即使从机不存在也会在 265ms 内收到 NACK。i2c-4 连 NACK 都没有。

### 已排除

驱动绑定 ✅ / pinmux ✅ / 时钟 ✅ / DT 配置 ✅ / SoC ✅ / App ✅ / SELinux（permissive）

### 请硬件方测量

**上电状态，万用表测 gpio4-10(SDA) / gpio4-11(SCL) 对地电压：**

| 读数 | 含义 |
|---|---|
| 约 3.3V | 上拉正常，查线序 / MCU 供电 |
| **0V** | 没有上拉电阻，或线路短路到地 |
| 1.65V 左右 | 上拉过弱或多个器件分压 |
| 跳动 | 接触不良 |

**同时建议插拔一次排线**——成本最低且最常见。

### 另一个发现

`getenforce` = **Permissive**。若量产 ROM 改为 Enforcing，
App 访问 sysfs 会被 SELinux 直接拒绝，表现为「权限拒绝」而非「总线故障」，
排查方向完全不同。**需要 ROM 侧补策略或保持 Permissive。**

## 六、部署必做（容易漏）

```bash
# 1. 安装
adb install app-release.apk

# 2. 授予所有文件访问（U 盘读写必需）
adb shell appops set com.btf.rk3568_hdmi_mediaplay MANAGE_EXTERNAL_STORAGE allow

# 3. 设为默认桌面（否则开机弹选择框，自动播放被挡）
adb shell cmd package set-home-activity --user 0 com.btf.rk3568_hdmi_mediaplay/.MainActivity
```

**无 adb 时的手动授权**：设置 → 所有文件访问权限 → 媒体播放器 →
打开「授予所有文件的管理权限」→ 返回 App（**自动加载，无需重启**）。

> ⚠️ 卸载重装会重置默认桌面设置，升级流程若含卸载需重跑第 3 步。

详细步骤：`docs/deployment-guide.md`

| 限制 | 原因 | 解法 |
|---|---|---|
| `show` 命令拉不起界面 | Android 11 后台启动限制（`isBgStartWhitelisted=false`） | 设备所有者 / Lock Task 白名单 |
